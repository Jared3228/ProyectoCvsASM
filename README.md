Nombre del alumno: Leonardo Jared Ley Gomez

# Descripcion del proyecto

El siguiente proyecto compara los tiempos de ejecución de una función para encontrar el numero mayor en un arreglo en C y en ensamblador. 

# Ensamble:
```
gcc -c main.c -o main.o
```

# Enlazamiento:
```
gcc main.o -o proyecto.exe
```

# Ejecucion

Comando para ejecutar en consola:
```
.\proyecto.exe
```
